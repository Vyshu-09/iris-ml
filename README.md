# Iris Species Prediction (MLOps Practicals 7, 8, 9)

Flask API that predicts Iris species from four measurements.

- `GET /` returns service status
- `POST /predict` returns the predicted species (JSON body with sepal_length, sepal_width, petal_length, petal_width)

Port: 5000. Image: ghcr.io/vyshu-09/iris-ml
